# User manuals of the core/* branches (TCdr/aircraft fork)

One user manual per `core/*` branch of the fork https://github.com/TCdr/aircraft. Each manual has one section per feature
of its branch, with what it is for, how to use it, how to test it in the sim (steps with the expected result) and the
test status of that feature.

- `manuals/00-index.html` / `.pdf`: the list of the 28 core branches, the base of each branch, the merge order of the
  stacked branches and the aircraft-large-files companion commits.
- `manuals/core-<scope>.html` / `.pdf`: the manual of `core/<scope>`.
- `manuals/FBW-user-manuals.pdf`: all manuals in one PDF, with bookmarks per manual and per feature.
  `manuals/FBW-user-manuals.docx` is the editable Word version.
- `manuals/img/`: the pictures the manuals use.

Rebuilt from scratch on 2026-10-09 from the branches as they are (develop `f1f32e63d`). Every manual was checked against
the commits on its branch, and every test status against the sim test records. A feature with no sim test record is
marked "Not sim-tested". The sources are generated by the manual generator (`E:\MSFS2024 mods\tools\manual-generator`,
`manuals/core/c_<scope>.py`, one file per branch; `manuals/core/info/<scope>.txt` lists the branch's own commits).

The older per-PR drafts (`NN-*.md`, `docs/`) of the `pr/NN` branches were removed on 2026-10-09: those branches are
replaced by the core branches. They remain in this branch's history.
