What it is for

A380 FCOM PRO-ABN-ECAM-10-24 has combined alerts for the loss of several busbars together. The A380X showed the single busbar alerts side by side instead.   • The fuel lines of these procedures depend on the flight time above FL 300 since departure (more or less than 30 min, counted from lift-off) and lead to gravity feeding (descent, CROSSFEED ... OFF, EXPECT NORM COLLECTOR CELL DEPLETION, AVOID NEG G LOAD), shown in flight only.

  • ELEC STATIC INV FAULT (crew awareness, phases 3 to 10 inhibited): the static inverter runs only on batteries (no AC ESS power, both battery contactors closed); it counts as failed when it runs but gives no normal output.

31. ATA 46 information system COM alerts and ATC RESET

Aircraft: A380X  |  Where: flyPad > Failures > ATA 46 and ATA 42; overhead NSS DATA TO AVNCS pb-sw and RESET panel (ATC RESET pb); E/WD, STATUS  |  Status: Not sim-tested. Develop (986919394 and 30af1a232, batches T2-36 and T2-27): unit tests only (CommunicationAlerts.spec.ts), no sim test recorded.

What it is for

Four COM alerts of the information system (A380 FCOM PRO-ABN-ECAM-10-46), inhibited in flight phases 3 to 7, 9 and 10:

  • COM ATC DATALINK FAULT: CPIOM D1 is lost, or the ATC RESET pb of the overhead RESET panel is pulled (the ATC datalink is powered down while it is pulled). STATUS INOP SYS: ATC DATALINK; LIMITATIONS: ATC COM VOICE ONLY.
  • COM ADS DATALINK FAULT: the ADS function is failed (new flyPad failure). STATUS INOP SYS: ADS DATALINK. With the whole ATC datalink lost only COM ATC DATALINK FAULT shows.
  • COM NSS DATA TO AVNCS XFR FAULT: the NSS DATA TO AVNCS pb-sw is OFF. STATUS INOP SYS: NSS DATA TO AVNCS.
  • COM NSS/AVNCS DATA XFR FAULT: both SCIs are failed (SCI 1 and SCI 2). It replaces the previous alert. STATUS INOP SYS: NSS/AVNCS DATA XFR.

The new flyPad failures are SCI 1 and SCI 2 (NSS / avionics secure communication interface) and ADS function (ATC datalink).

Limitations and why

LimitationWhyWhat to do
Only the alerts: pulling ATC RESET does not power-cycle the ATC datalink here, and there is no SD mailbox or KCCU effect.Those parts of the same change are not on this branch.Not placed on a core branch yet.
Losing VHF 3 or both SCIs does not stop the datalink or the AOC.Those effects are on core/a380x-ois-datalink.Merge it for the effects; here only the alerts show.
The COM NSS DATA TO AVNCS XFR FAULT alert from a single faulty SCI is not simulated.Only the pb-sw OFF case gives it; both SCIs lost give the next alert.-

How to use

  1. On COM ATC DATALINK FAULT, use voice for ATC; push the ATC RESET pb back in if it was pulled.
  2. On the NSS alerts, set the NSS DATA TO AVNCS pb-sw to ON; with both SCIs lost nothing can be done in the cockpit.
