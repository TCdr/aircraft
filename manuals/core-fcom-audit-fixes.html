7. A32NX climb thrust regression test

Aircraft: A32NX  |  Where: Unit tests (FMS and FADEC climb thrust tables)  |  Status: Test only, no code change: A320ClimbThrustLimit.spec.ts passes.

What it is for

A check of the A32NX climb against the A320neo FCOM climb tables (IndiGo FCOM PER-CLB-CLT, PDF pages 7248-7250 at ISA+10 and 7258-7260 at ISA+20, PW1127G-JM engines; no LEAP-1A table is available) found that the A32NX already climbs within 1-3 % of them, so no CLB thrust value was changed. The test keeps it so: the FADEC CLB N1 table (ThrustLimits_A32NX.hpp) and its FMS copy (cn1ClimbLimit) must stay identical row by row, and a climb computed with the FMS engine and flight models from FL 100 to FL 300 at 300 kt / M.78 must stay within 5 % of the FCOM times (8 % for each half) at 52 to 76 t.

Limitations and why

LimitationWhyWhat to do
Nothing changes in the aircraft.The finding was that the climb already matches the FCOM.-
The reference is the PW1127G-JM table.FBW models the LEAP-1A26; no LEAP climb table is available.-

How to use

  1. Nothing to do in the sim. When changing the CLB N1 table, change both copies and run the test.

How to test

#Do thisExpected result
1Run npx vitest run fbw-a32nx/src/systems/fmgc/src/flightplanning/A320ClimbThrustLimit.spec.ts.All tests pass.
