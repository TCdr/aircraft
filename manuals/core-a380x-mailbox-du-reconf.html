1. ATC mailbox follows the SD to the ND display unit

Aircraft: A380X  |  Where: F/O DU RECONF pb; ATC mailbox on the F/O (or CAPT) ND DU  |  Status: Tested in the sim by the user on the integration build: OK (2026-10-11, session A, test M1: SD off, F/O DU RECONF twice, mailbox on the F/O ND with its buttons, back on the SD with the same queue). Not sim-tested on this core branch. Unit tests: AtcMailbox.spec.tsx, MailboxLogic.spec.ts, MailboxBus.spec.ts, CdsReconfiguration specs, HostedDisplay.spec.ts.

What it is for

The ATC mailbox is the bottom section of the SD. The CDS SD DU FAULT procedure says "If the SD DU is turned OFF, use the F/O DU RECONF P/B for ATC mailbox" (A380 FCOM PRO-ABN-ECAM-10-31, a380_fcom.txt l.157950 and l.158167). On core/display-unit-failures the F/O DU RECONF pb brings the SD to the F/O ND DU, but without the mailbox, so the ATC messages could not be read or answered with the SD DU off. Now the mailbox comes with the SD.

What you should see

SituationWhat you should see

The SD shown both on the SD DU and on an ND DU (DU RECONF used because of another failed DU)The SD DU's mailbox is the active one; the mailbox on the ND DU shows the same message and takes no input (design choice).
The SD shown nowhereNo mailbox marks a new message as displayed or read: the ATC MSG lights stay on until a DU shows the mailbox again (design choice).
PRINT in the mailboxPRINT NOT AVAIL (no cockpit printer on this branch; printing is on core/printer).

How it works

  • The systems host decides which DU has the active mailbox (L:A380X_CDS_MAILBOX_DU): the SD DU while it is working and shows the SD, else the ND DU that shows the SD (the SD is never on both sides at once, FCOM DSC-31-15-20), else none.
  • Only the active mailbox answers the crew and sends to the ATC function; another mailbox on screen mirrors the displayed message.
  • The A380X README and the simvar documentation describe the variable and the rule.

How to use

  1. With the SD DU off or failed (CDS SD DU FAULT), press the F/O DU RECONF pushbutton (glareshield, F/O side) until the F/O ND DU shows the SD: first the E/WD, then the SD with the mailbox.
  2. Read and answer the ATC messages in the mailbox on the F/O ND with the F/O cursor, as on the SD.
  3. Press F/O DU RECONF once more to get the ND back, or switch the SD DU back on.
